# Veille bibliographique

Une fiche par phase, 2-3 sources et une synthèse — le format prévu dans la roadmap initiale du projet, ajouté ici après coup.

- [Phase 1 — Séquences ARN/ADN](phase1_biopython.md) : mutation ESR1 Y537S, curation NCBI RefSeq
- [Phase 2 — Chémoinformatique](phase2_chemoinformatique.md) : règle de Lipinski, empreintes de Morgan, BRICS, split par squelette, résistance PIK3CA
- [Phase 3 — Biologie des systèmes](phase3_biologie_systemes.md) : voie HER2/PI3K/AKT, modélisation ODE, Tellurium
- [Phase 4 — Base de données](phase4_base_donnees.md) : GDSC, classification moléculaire des lignées cellulaires, lapatinib

**Note de méthode** : ces fiches indiquent où trouver de l'information et en donnent une synthèse pour orienter la lecture — elles ne remplacent pas la vérification de la source primaire avant citation formelle dans un document officiel (règle de veille standard, pas spécifique à ce projet).
